FinanceFlow palettes

Proposed colour themes for the Stillwater design system, each shown on a sample Home card in light and dark. Every number below was computed from these exact colours: WCAG contrast for text (needs 4.5:1) and control borders/focus (needs 3:1), and a colour-blindness simulation for the money colours.

  • Money colours are shared across palettes so income always looks like income. Sandstone is the one exception, explained in its own section.
  • Income vs expense is the only money pair that must survive colour blindness on colour alone (target ΔE ≥ 10). Transfer, savings, debt and investment always carry an icon and a label as well.
  • Lichen's expense colour moves from raspberry to brick. The old pair scored ΔE 5.8 for deuteranopia, which reads as nearly the same colour.
