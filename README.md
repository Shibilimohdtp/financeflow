# FinanceFlow

**Private, Local-First Personal Finance Platform**

FinanceFlow is a privacy-first personal finance platform built with Flutter and designed around the **Stillwater** design system. It automatically tracks, categorizes, analyzes, and forecasts personal finances without relying on centralized cloud databases or backend servers.

All financial data remains 100% on the user's device.

---

## Key Principles

- **Privacy First**: 0 bytes stored on remote servers. No tracking, no centralized telemetry, no ad networks.
- **Local First**: Encrypted on-device storage using Isar Database with full biometric and PIN protection.
- **Calm Visual Precision**: Powered by the **Stillwater** design system — deep water teals, warm sand neutrals, and restrained marigold accents.
- **Multi-Source Ingestion**: On-device SMS parsing, financial notification listeners, Gmail statement ingestion, and CSV/XLSX imports.
- **Intelligent Financial Modeling**: Real-time cashflow tracking, category budgeting, subscription management, loan/EMI amortization schedules, and savings goals.

---

## Stillwater Brand Identity

The **Stillwater Mark** is the visual identity of FinanceFlow:
- **Calm Boundary**: Concentric fluid ripples representing privacy and contained local ownership.
- **Dynamic Current**: Subtle ascending flow geometry embodying upward financial health and movement of money.
- **Protected Core**: A warm marigold spark signifying value and on-device intelligence.

---

## Tech Stack & Architecture

- **Framework**: Flutter (Material 3 · Adaptive Design)
- **State Management**: Flutter Riverpod & StateNotifier
- **Local Database**: Encrypted Isar Database
- **Secure Storage**: Flutter Secure Storage (Hardware Keystore / Keyring)
- **Design System**: Stillwater Design System (`lib/theme/`)
